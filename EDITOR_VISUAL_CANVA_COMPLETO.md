```
PASSO 2: Clique no canvas
```

### Propriedades de Formas

```
┌─────────────────────────┐
│ PROPRIEDADES            │
├─────────────────────────┤
│ Posição e Tamanho       │
│ X: [200]  Y: [100]      │

├─────────────────────────┤
│ Cor de Preenchimento    │

├─────────────────────────┤

│ (50+ = círculo)         │
├─────────────────────────┤
│ [✓] Sombra             │
│                         │
│ Se ativado:             │
│ • X: deslocamento       │
│ • Y: deslocamento       │
│ • Blur: suavidade       │
│ • Cor: rgba             │
├─────────────────────────┤
│ Rotação                 │
│ ┣━━●━━━━━━┫ 0°        │
├─────────────────────────┤
│ Opacidade               │
│ ┣━━━━━━━━●┫ 100%      │
├─────────────────────────┤
│ [📋 Duplicar]          │
│ [🔒 Bloquear]          │
│ [🗑️ Excluir]           │
└─────────────────────────┘
```

### Exemplos de Formas

**Retângulo:**
- Raio: 0px
- Uso: caixas, divisórias

**Retângulo Arredondado:**
- Raio: 12px
- Uso: cards, botões

**Círculo:**
- Raio: 100px (metade do tamanho)
- W = H (mesmo tamanho)
- Uso: avatares, ícones

**Linha Horizontal:**
- Altura: 2-4px
- Largura: 100%
- Uso: separadores

## 🎯 Funcionalidades Avançadas

### 1. Drag & Drop
```
Como usar:
1. Clique em [🖱️ Selecionar]
2. Clique e segure um elemento
3. Arraste para nova posição
4. Solte o mouse
```

### 2. Redimensionar
```
Como usar:
1. Selecione um elemento
2. Painel direito > Tamanho
3. Digite novos valores
4. OU use as alças (futuro)
```

### 3. Rotação
```
Gire qualquer elemento:
┣━━●━━━━━━┫
0°        180°       360°

Uso:
- Textos diagonais
- Formas inclinadas
- Efeitos criativos
```

### 4. Opacidade (Transparência)
```
┣━━━━━━━━●┫
0%   50%   100%
↑     ↑      ↑
Invisível Semi Opaco

Uso:
- Marcas d'água
- Sobreposições
- Efeitos de camada
```

### 5. Z-Index (Camadas)
```
Ordem de sobreposição:

[3] ← Mais na frente
[2]
[1]
[0] ← Mais atrás

Automático:
- Elementos novos vão para frente
- Próxima versão: reorganizar manualmente
```

### 6. Lock/Unlock
```
🔓 Desbloqueado:
- Pode mover
- Pode editar
- Pode deletar

🔒 Bloqueado:
- NÃO pode mover
- NÃO pode editar
- Protegido contra mudanças

Uso: travar logos, cabeçalhos fixos
```

### 7. Grid e Snap
```
# Grid (Grade):
┌─┬─┬─┬─┬─┐
├─┼─┼─┼─┼─┤
├─┼─┼─┼─┼─┤
└─┴─┴─┴─┴─┘

Tamanho: 10px (padrão)

Snap to Grid:
✅ Ativado → encaixa na grade
❌ Desativado → posição livre
```

### 8. Undo/Redo
```
Top bar:
[↶ Undo] [↷ Redo]

Histórico completo:
- Toda ação é salva
- Volte quantas vezes quiser
- Refaça se mudou de ideia
```

### 9. Zoom
```
[−] 25% 50% 75% [100%] 125% 150% 200% [+]

Use para:
- Trabalho detalhado (zoom in)
- Visão geral (zoom out)
- Acessibilidade
```

## 🗄️ Estrutura do Banco de Dados

### 6 Novas Tabelas Criadas

1. **document_canvas_designs**
   ```sql
   - canvas_width, canvas_height
   - background_type, background_color
   - background_gradient, background_image
   - grid_enabled, snap_to_grid
   - margins, orientation
   ```

2. **document_canvas_elements**
   ```sql
   - element_type (text, shape, image)
   - x, y, width, height
   - rotation, z_index
   - font_family, font_size, font_weight
   - fill_color, fill_gradient
   - border_radius, shadows
   ```

3. **design_templates**
   ```sql
   - Templates visuais prontos
   - canvas_design (JSON)
   - elements (JSON array)
   - category, tags
   ```

4. **design_assets**
   ```sql
   - Biblioteca de assets
   - images, icons, illustrations
   - Futuro: upload de arquivos
   ```

5. **design_fonts**
   ```sql
   - 10 fontes pré-cadastradas
   - Google Fonts integration
   - font_family, weights
   ```

6. **design_history**
   ```sql
   - Histórico de ações
   - Undo/Redo data
   - action_type, action_data
   ```

## 🚀 Fluxo de Uso Completo

### Cenário: Criar Orçamento Visual

**PASSO 1: Escolher Template**
```
1. Acesse /documents
2. Aba "Templates"
3. Hover no card "Orçamento Elegante"
4. Clique em [Visual] (botão roxo)
```

**PASSO 2: Configurar Fundo**
```
1. Clique no ícone 🎨 Palette
2. Tipo: Degradê
3. Escolha: Azul Corporativo
4. Fechar painel
```

**PASSO 3: Adicionar Título**
```
1. Clique em [📝 Text]
2. Clique no canvas (topo)
3. Digite: "ORÇAMENTO TÉCNICO"
4. Painel direito:
   - Fonte: Montserrat
   - Tamanho: 36px
   - Negrito: ON
   - Cor: Branco
   - Alinhamento: Centro
```

**PASSO 4: Adicionar Caixa de Destaque**
```
1. Clique em [📐 Shape]
2. Clique no canvas
3. Painel direito:
   - Largura: 700
   - Altura: 200
   - Cor: Verde (#10b981)
   - Raio: 16px
   - Sombra: ON
```

**PASSO 5: Adicionar Informações**
```
1. [📝 Text] → "Cliente: {{cliente}}"
2. [📝 Text] → "Valor: R$ {{valor}}"
3. [📝 Text] → "Validade: {{validade}}"
```

**PASSO 6: Ajustar Grid**
```
1. Clique no ícone # Grid
2. Grade ativa
3. Elementos encaixam automaticamente
4. Alinhamento perfeito
```

**PASSO 7: Salvar**
```
1. Revise tudo visualmente
2. Clique em [💾 Salvar]
3. Design salvo no banco
4. Reutilizável para próximos orçamentos
```
