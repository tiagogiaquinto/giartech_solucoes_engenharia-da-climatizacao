# 📍 ONDE ENCONTRAR OS TEMPLATES HVAC

## ✅ ACESSO RÁPIDO

### Opção 1: Pelo Menu Lateral (Sidebar)

```
1. Abra o sistema
```

- Antes de "Configurações"

## 🔧 COMO USAR

### Para Usar um Template

```
1. Localize o template desejado
2. Clique no botão "Usar" (azul)
3. Preencha os dados
4. Gere o documento
```

### Para Editar um Template

```
1. Clique no ícone de lápis (Editar)
2. Use o Editor Avançado com 5 abas:
   - Conteúdo
   - Variáveis
   - Blocos
   - Tema
   - Preview
3. Faça suas alterações
4. Clique em "Salvar"
```

### Para Duplicar

```
1. Clique no ícone de copiar (Duplicar)
2. Uma cópia é criada com o nome "(Cópia)"
3. Edite a cópia como quiser
4. Salve com novo nome
```

---

## 🎨 PERSONALIZAÇÃO

### Mudar Cores

1. Abra o template no editor
2. Vá na aba "Conteúdo"
3. Localize os códigos de cor (ex: #0284c7)
4. Substitua pela cor desejada
5. Salve

### Adicionar Logo

1. Abra o template no editor
2. Localize a seção do cabeçalho
3. Adicione tag `<img src="URL_DO_LOGO">`
4. Ajuste tamanho conforme necessário
5. Salve

### Modificar Textos

1. Abra o template no editor
2. Localize o texto desejado
3. Altere diretamente
4. Use variáveis se precisar dados dinâmicos
5. Salve

---

## 💡 DICAS IMPORTANTES

### ✅ FAÇA

- Teste cada template antes de usar com clientes
- Personalize com as cores da sua empresa
- Adicione seu logo no cabeçalho
- Mantenha backup dos templates originais (duplicando)
- Revise sempre antes de enviar ao cliente

### ⚠️ NÃO FAÇA

- Não delete os templates originais (duplique primeiro)
- Não esqueça de salvar após editar
- Não remova variáveis importantes como {{customer.name}}
- Não use cores muito fortes que dificultem leitura

---

## 🆘 PROBLEMAS COMUNS

### "Não encontro o menu Templates HVAC"

**Solução:**
1. Limpe o cache do navegador (Ctrl + F5)
2. Faça logout e login novamente
3. Acesse diretamente: /template-manager

### "Templates não aparecem"

**Solução:**
1. Verifique conexão com internet
2. Recarregue a página
3. Verifique filtros (podem estar ocultando)

### "Não consigo editar"

**Solução:**
1. Verifique se clicou no botão certo (lápis)
2. Verifique permissões de usuário
3. Tente duplicar primeiro e edite a cópia
