## 🚀 Como Usar

### **1. Acessar o Sistema**

```
Menu Principal → 📄 Orçamentos
ou
URL: /budgets
```

### **2. Criar Novo Orçamento**

1. Clique em **[+ Novo Orçamento]**
2. Preencha os dados do cliente:
   - Nome/Razão Social
   - CPF/CNPJ
   - Email e Telefone
3. Configure datas:
   - Data de emissão
   - Validade (padrão: 30 dias)

### **3. Adicionar Itens**

Para cada item do orçamento:

```
┌─────────────────────────────────────┐
│ Descrição: Serviço de manutenção   │
│ Quantidade: 2                       │
│ Unidade: UN                         │
│ Valor Unitário: R$ 500,00           │
│ [Adicionar]                         │
└─────────────────────────────────────┘
```

**Cálculo Automático:**
- Total do item = Quantidade × Valor Unitário
- Subtotal = Soma de todos os itens
- Total = Subtotal - Desconto + Impostos

### **4. Configurar Descontos**

Duas opções disponíveis:

- **Percentual (%)**: Desconto sobre o subtotal
  - Exemplo: 10% sobre R$ 1.000,00 = R$ 100,00

- **Valor Fixo (R$)**: Desconto em reais
  - Exemplo: R$ 50,00 de desconto

### **5. Adicionar Informações Extras**

**Condições de Pagamento:**
```
Ex: 50% na assinatura do contrato
    50% na entrega do serviço

    Ou: Parcelamento em 3x sem juros
```

**Observações:**
```
- Garantia de 12 meses
- Prazo de entrega: 15 dias úteis
- Materiais inclusos no orçamento
```

### **6. Selecionar Template**

Clique em **[Templates]** e escolha o estilo:

```
┌──────────┬──────────┬──────────┬──────────┐
│ Profis.  │ Técnico  │ Moderno  │ Clássico │
│  [Azul]  │ [Verde]  │ [Roxo]   │ [Cinza]  │
└──────────┴──────────┴──────────┴──────────┘
```

### **7. Visualizar e Salvar**

- **[Visualizar]**: Ver preview do PDF
- **[Baixar]**: Download do arquivo
- **[Imprimir]**: Impressão direta
- **[Salvar]**: Salvar orçamento

## 💡 Dicas de Uso

### **1. Numeração Automática**

O sistema gera números únicos automaticamente:
```
ORC-1734563789000
ORC-1734563792000
...
```

Você pode personalizar na edição:
```
ORC-2025-001
PROP-2025-JAN-001
```

### **2. Validade Inteligente**

- Padrão: 30 dias após emissão
- Expiração automática
- Status muda para "Expirado" automaticamente

### **3. Cálculos Automáticos**

Tudo é calculado em tempo real:

```
Item 1: 2 × R$ 500,00 = R$ 1.000,00
Item 2: 1 × R$ 300,00 = R$ 300,00
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Subtotal:              R$ 1.300,00
Desconto (10%):        -R$ 130,00
Impostos:              +R$ 50,00
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
TOTAL:                 R$ 1.220,00
```

### **4. Preview Instantâneo**

Sempre que clicar em **[Visualizar]**:
- PDF gerado em tempo real
- Visualização inline no navegador
- Pronto para download/impressão

### **5. Duplicar para Agilidade**

Para criar orçamento similar:
1. Clique em **[Duplicar]**
2. Sistema cria cópia completa
3. Novo número gerado automaticamente
4. Edite apenas o necessário

## 📞 Suporte

### **Problemas Comuns:**

**1. PDF não gera**
- Verificar dados obrigatórios preenchidos
- Limpar cache do navegador
- Tentar outro template

**2. Cálculos errados**
- Verificar formato dos números
- Conferir tipo de desconto (% ou R$)
- Recarregar página

**3. Não consegue salvar**
- Verificar conexão com internet
- Conferir campos obrigatórios
- Ver console para erros
