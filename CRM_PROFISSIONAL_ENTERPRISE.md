### 4. 📈 **FORECASTING AVANÇADO**

Previsão de vendas baseada em probabilidade:

#### **Métricas Calculadas:**
```
💰 VALOR PONDERADO
   Valor do Deal × Probabilidade do Stage

   Exemplo:
   Deal de R$ 100.000 no stage "Proposta" (30%)
   Valor Ponderado = R$ 100.000 × 0,30 = R$ 30.000

📊 FORECAST POR PERÍODO
   - Mês atual
   - Próximo mês
   - Trimestre
   - Ano

🎯 PROBABILIDADE CUSTOMIZÁVEL
   - Usar probabilidade do stage
   - Definir probabilidade custom por deal
   - Ajustar baseado em histórico

📉 ANÁLISE DE TENDÊNCIAS
   - Pipeline velocity
   - Taxa de conversão
   - Ciclo de venda médio
   - Metas vs Realizado
```

#### **Dashboard de Forecast:**

### 7. 🤖 **AUTOMAÇÕES AVANÇADAS**

Automação inteligente do CRM:

#### **Triggers Disponíveis:**
```
🔄 MUDANÇA DE STAGE
   Quando: Oportunidade muda de etapa
   Exemplo: Stage = "Proposta" → Enviar template de proposta

📝 MUDANÇA DE CAMPO
   Quando: Campo específico é alterado
   Exemplo: Lead Score > 80 → Notificar gerente

⏰ BASEADO EM TEMPO
   Quando: Data/hora específica
   Exemplo: Todo dia às 9h → Listar tarefas do dia

📊 MUDANÇA DE SCORE
   Quando: Lead score aumenta/diminui
   Exemplo: Score cai 20 pontos → Alertar vendedor

✅ ATIVIDADE COMPLETADA
   Quando: Tarefa/reunião completada
   Exemplo: Meeting done → Criar follow-up task

📧 EMAIL ABERTO
   Quando: Email é aberto pelo cliente
   Exemplo: Email aberto 3x → Ligar imediatamente
```

#### **Ações Disponíveis:**
```
📧 ENVIAR EMAIL
   - Template personalizado
   - Com anexos
   - Para múltiplos destinatários

📝 CRIAR TAREFA
   - Título automático
   - Prazo calculado
   - Atribuir responsável

🔔 NOTIFICAÇÃO
   - In-app
   - Push
   - SMS
   - WhatsApp

🔄 MUDAR STAGE
   - Avançar/retroceder
   - Baseado em condições

🏷️ ADICIONAR TAG
   - Categorização automática
   - Segmentação

📊 ATUALIZAR CAMPO
   - Score
   - Temperatura
   - Qualquer campo custom

👤 ATRIBUIR OWNER
   - Round-robin
   - Por território
   - Por especialidade
   - Por carga de trabalho
```

#### **Exemplos de Automações:**
```
AUTOMAÇÃO 1: "Follow-up Automático"
Trigger: Oportunidade sem atividade há 3 dias
Condições:
  - Status = Aberto
  - Stage != Fechamento
Ações:
  1. Criar tarefa "Follow-up necessário"
  2. Enviar email ao responsável
  3. Adicionar tag "needs-attention"

AUTOMAÇÃO 2: "Lead Quente"
Trigger: Lead score > 85
Condições:
  - Temperatura != Quente
  - Não tem reunião agendada
Ações:
  1. Mudar temperatura para "Quente"
  2. Notificar gerente
  3. Criar tarefa "Ligar urgente"
  4. Prioridade = Alta

AUTOMAÇÃO 3: "Proposta Enviada"
Trigger: Stage muda para "Proposta"
Ações:
  1. Enviar email template "Proposta"
  2. Agendar follow-up em 2 dias
  3. Atualizar campo "Data Proposta"
  4. Iniciar sequência de emails

AUTOMAÇÃO 4: "Deal Ganho"
Trigger: Status muda para "Ganho"
Ações:
  1. Notificar toda equipe
  2. Criar projeto no sistema
  3. Enviar onboarding email
  4. Adicionar ao CRM pós-venda
  5. Calcular comissão
```
