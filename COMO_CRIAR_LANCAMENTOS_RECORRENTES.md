## 🎯 O QUE SÃO LANÇAMENTOS RECORRENTES?

Lançamentos recorrentes são **receitas ou despesas que se repetem** periodicamente:

✅ Aluguel mensal
✅ Folha de pagamento
✅ Mensalidades de serviços
✅ Contratos de clientes
✅ Contas de luz, água, internet
✅ Seguros anuais
✅ Manutenções periódicas

## 🚀 COMO CRIAR UM LANÇAMENTO RECORRENTE

### Método 1: Criar Novo Lançamento Recorrente

#### Passo 1: Acesse Gestão Financeira
```
Menu → Financeiro → Gestão Financeira
```

#### Passo 2: Clique em "Novo Lançamento"
```
Botão azul no topo: "+ Novo Lançamento"
```

#### Passo 3: Preencha os Dados Básicos

**Campos obrigatórios:**
```
✅ Descrição: "Aluguel Escritório"
✅ Valor: R$ 5.000,00
✅ Tipo: Despesa (ou Receita)
✅ Status: A Pagar (ou A Receber)
✅ Data: 09/01/2026
✅ Data de Vencimento: 09/01/2026
```

**Campos opcionais:**
```
□ Categoria
□ Forma de Pagamento
□ Cliente/Fornecedor
□ Conta Bancária
□ Observações
```

#### Passo 4: Ativar Recorrência

**Marque o checkbox:**
```
☑️ Este é um lançamento recorrente
```

**Configure a frequência:**
```
┌─────────────────────────────────┐
│ Frequência: [Mensal ▼]          │
│ Dia do mês: [5]                 │
│ Data inicial: [09/01/2026]      │
│ Data final: [___] (opcional)    │
│ Contador: [___] (opcional)      │
│ Status: [Ativo ▼]               │
│ ☑️ Gerar automaticamente         │
└─────────────────────────────────┘
```

#### Passo 5: Salvar

```
Clique em "Salvar"
```

**O que acontece automaticamente:**
✅ Lançamento recorrente é criado
✅ Sistema gera próximos 12 meses automaticamente
✅ Lançamentos futuros aparecem na lista
✅ Você pode visualizar na agenda
✅ Aparece no calendário de recorrências

---

### Método 2: Transformar Lançamento Existente em Recorrente

#### Passo 1: Encontre o Lançamento
```
Menu → Financeiro → Gestão Financeira
Procure o lançamento que deseja tornar recorrente
```

#### Passo 2: Edite o Lançamento
```
Clique no ícone de editar (✏️) na linha do lançamento
```

#### Passo 3: Ative a Recorrência
```
☑️ Marque "Este é um lançamento recorrente"
Configure frequência, dia, etc.
```

#### Passo 4: Salve
```
Clique em "Salvar"
Sistema gera automaticamente os próximos 12 meses
```

## 📅 FREQUÊNCIAS DISPONÍVEIS

### 1. Semanal
```
Descrição: A cada 7 dias
Exemplo: Toda segunda-feira
Ocorrências: ~52 por ano
```

### 2. Quinzenal
```
Descrição: A cada 15 dias
Exemplo: Dias 1 e 15 do mês
Ocorrências: ~24 por ano
```

### 3. Mensal ⭐ (MAIS USADO)
```
Descrição: Todo mês no mesmo dia
Exemplo: Todo dia 5
Ocorrências: 12 por ano
```

**Exemplo prático:**
```
Dia configurado: 5
Resultado:
  05/02/2026
  05/03/2026
  05/04/2026
  ...
  05/01/2027
```

### 4. Bimestral
```
Descrição: A cada 2 meses
Exemplo: Jan, Mar, Mai, Jul, Set, Nov
Ocorrências: 6 por ano
```

### 5. Trimestral
```
Descrição: A cada 3 meses
Exemplo: Jan, Abr, Jul, Out
Ocorrências: 4 por ano
```

### 6. Semestral
```
Descrição: A cada 6 meses
Exemplo: Jan e Jul
Ocorrências: 2 por ano
```

### 7. Anual
```
Descrição: Uma vez por ano
Exemplo: Todo 15/01
Ocorrências: 1 por ano
```

## ⚙️ CONFIGURAÇÕES AVANÇADAS

### Data Final (Opcional)
```
Quando configurado: Sistema para de gerar após essa data
Quando vazio: Gera indefinidamente

Exemplo:
Data final: 31/12/2026
→ Sistema gera apenas até dezembro/2026
```

### Contador (Opcional)
```
Quando configurado: Sistema gera apenas N ocorrências
Quando vazio: Gera indefinidamente

Exemplo:
Contador: 12
→ Sistema gera apenas 12 meses
```

### Status da Recorrência

**Ativo:**
```
✅ Sistema gera automaticamente
✅ Lançamentos futuros são criados
✅ Aparece nas previsões
```

**Pausado:**
```
⏸ Sistema não gera novos
⏸ Lançamentos existentes permanecem
⏸ Pode retomar a qualquer momento
```

**Cancelado:**
```
❌ Sistema não gera mais
❌ Recorrência foi encerrada
❌ Pode cancelar lançamentos futuros
```

**Finalizado:**
```
✓ Recorrência completou ciclo
✓ Data final atingida OU contador completo
✓ Sistema definiu automaticamente
```

### Geração Automática

**Ativado (recomendado):**
```
✅ Sistema gera automaticamente ao criar
✅ Gera próximos 12 meses na hora
✅ Você só clica em "Salvar" e está pronto
```

**Desativado:**
```
□ Sistema NÃO gera automaticamente
□ Você precisa gerar manualmente
□ Use o botão "Gerar Recorrências"
```

## 🔄 BOTÃO "GERAR RECORRÊNCIAS"

### Quando Usar

**Use este botão quando:**

1. **Primeira vez que usa o sistema**
   ```
   Criou várias recorrências de uma vez
   Quer gerar todos os 12 meses agora
   ```

2. **Recorrência com geração desativada**
   ```
   Criou com ☐ Gerar automaticamente desmarcado
   Agora quer gerar os próximos meses
   ```

3. **Atualização mensal**
   ```
   Início do mês
   Quer garantir que está tudo atualizado
   ```

4. **Após alterações**
   ```
   Mudou valor da recorrência
   Mudou frequência
   Quer regenerar com novos dados
   ```

5. **Verificação**
   ```
   Quer confirmar que tudo foi gerado
   Quer ver quantos lançamentos foram criados
   ```

### Como Usar

#### Passo 1: Acesse
```
Menu → Financeiro → Gestão Financeira
```

#### Passo 2: Clique no Botão Verde
```
🔄 Gerar Recorrências
(No topo, ao lado do botão roxo)
```

#### Passo 3: Confirme
```
Mensagem:
"Deseja gerar todos os lançamentos recorrentes
para os próximos 12 meses?"

Clique: OK
```

#### Passo 4: Aguarde
```
Botão mostra: 🔄 Gerando... (animado)
```

#### Passo 5: Veja o Resultado
```
✅ Geração concluída!

📊 Recorrências processadas: 5
✨ Lançamentos criados: 48
❌ Erros: 0
📅 Meses gerados: 12
```

### O Que o Botão Faz

**Para cada recorrência ativa:**
1. ✅ Verifica a frequência (mensal, trimestral, etc)
2. ✅ Calcula os próximos 12 meses
3. ✅ Cria os lançamentos faltantes
4. ✅ **NÃO duplica** (se já existe, pula)
5. ✅ Respeita data final (se configurada)
6. ✅ Respeita contador (se configurado)
7. ✅ Registra no histórico
8. ✅ Atualiza contadores

## 🚨 RESOLUÇÃO DE PROBLEMAS

### Problema: Não vejo lançamentos futuros

**Soluções:**

1. **Limpar filtros**
   ```
   Remova filtros de mês/ano
   Remova filtros de data
   ```

2. **Verificar ordenação**
   ```
   Ordenar por: Data de Vencimento
   Ordem: Crescente
   ```

3. **Verificar se criou recorrência**
   ```
   Filtro: Apenas Recorrentes
   Deve mostrar pelo menos 1 lançamento
   ```

4. **Clicar em "Gerar Recorrências"**
   ```
   Botão verde no topo
   Confirmar geração
   ```

5. **Atualizar página**
   ```
   F5 ou Ctrl+R
   ```

---

### Problema: Gerou poucos lançamentos

**Motivos possíveis:**

1. **Data final configurada**
   ```
   Sistema para na data final
   Edite para estender ou remova
   ```

2. **Contador limitado**
   ```
   Sistema para no contador
   Edite para aumentar ou remova
   ```

3. **Frequência é semestral/anual**
   ```
   Normal ter poucas ocorrências
   12 meses = 2 semestrais ou 1 anual
   ```

4. **Já existiam lançamentos**
   ```
   Sistema não duplica
   Mostra apenas novos criados
   ```

---

### Problema: Gerou duplicado

**Soluções:**

1. **Não deveria acontecer**
   ```
   Sistema tem proteção contra duplicação
   ```

2. **Pode ser lançamento manual + automático**
   ```
   Você criou manualmente E sistema gerou
   Exclua um dos dois
   ```

3. **Datas ligeiramente diferentes**
   ```
   Pode não ser duplicata
   Verifique as datas exatas
   ```
