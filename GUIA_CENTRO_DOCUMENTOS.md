## 🚀 Como Criar Seu Primeiro Documento

### PASSO 1: Acesse o Centro de Documentos
```
Menu > Centro de Documentos
ou
Digite: /documents
```

### PASSO 2: Configure a Empresa (Primeira Vez)
```
1. Clique na aba "Configurações"
2. Preencha os dados da empresa
3. Configure responsável técnico
4. Adicione dados bancários
5. Personalize as cores
6. Clique em "Salvar Configurações"
```

### PASSO 3: Escolha um Template
```
1. Clique na aba "Templates"
2. Navegue pelos cards de documentos
3. Clique em "Gerar" no template desejado
```

### PASSO 4: Preencha os Dados
```
Um modal abrirá com todos os campos:
```

## 📝 Exemplo Prático: Criando um Contrato

### 1. Configure a Empresa (Se Ainda Não Fez)
```
Configurações > Preencher dados da empresa
```

### 2. Gere o Contrato
```
Templates > Card "Contrato de Prestação de Serviços" > Gerar
```

### 3. Preencha os Dados do Contrato
```
CONTRATANTE:
  Nome: João Silva
  CPF/CNPJ: 123.456.789-00
  Endereço: Rua A, 123

CONTRATADA:
  (Preenchido automaticamente com dados da empresa)

OBJETO:
  manutenção preventiva e corretiva de sistemas
  de climatização conforme PMOC vigente

VALOR:
  Total: 5000.00
  Por Extenso: cinco mil reais
  Forma: Mensalmente via PIX

PRAZO:
  Execução: 12 meses
  Início: 2024-12-18
  Término: 2025-12-18

CLÁUSULAS:
  Obrigações Contratada: [preencher]
  Obrigações Contratante: [preencher]
  Garantia: [preencher]
  Rescisão: [preencher]
  Penalidades: [preencher]

TESTEMUNHAS:
  1. Nome + CPF
  2. Nome + CPF
```

### 4. Clique em "Gerar PDF"
```
✅ Contrato gerado!
✅ Número: 000001-2024-CON
✅ PDF baixado
✅ Salvo no histórico
```

## 🎯 Casos de Uso por Documento

### 🛡️ PMOC
**Quando usar:**
- Obrigatório para sistemas de climatização
- Renovação anual
- Auditoria de órgãos fiscalizadores

**Campos principais:**
- Dados do sistema
- Periodicidade de manutenções
- Procedimentos operacionais
- Controle de qualidade do ar

---

### 📝 Contrato de Prestação de Serviços
**Quando usar:**
- Formalizar parceria com clientes
- Manutenções recorrentes
- Projetos de longo prazo

**Campos principais:**
- Partes (contratante/contratada)
- Objeto dos serviços
- Valores e forma de pagamento
- Cláusulas contratuais

---

### 💰 Orçamento Técnico
**Quando usar:**
- Propostas comerciais
- Orçamentos detalhados
- Apresentação de custos

**Campos principais:**
- Cliente
- Itens/Serviços
- Valores unitários e totais
- Condições de pagamento

---

### 🏆 Termo de Garantia
**Quando usar:**
- Após conclusão de serviços
- Entrega de equipamentos
- Instalações e reformas

**Campos principais:**
- Serviço realizado
- Prazo de garantia
- Cobertura e exclusões
- Condições de acionamento

---

### 📋 Relatório Técnico
**Quando usar:**
- Documentar serviços executados
- Registrar diagnósticos
- Histórico de atendimentos

**Campos principais:**
- Situação encontrada
- Diagnóstico técnico
- Serviços executados
- Resultados e recomendações

---

### 📊 Laudo Técnico
**Quando usar:**
- Avaliações técnicas oficiais
- Vistorias especializadas
- Documentos com responsabilidade técnica

**Campos principais:**
- Responsável técnico (CREA/CRT)
- Metodologia de avaliação
- Análise técnica detalhada
- Conclusão fundamentada

---

### ✅ Check-list de Manutenção
**Quando usar:**
- Manutenções preventivas
- Inspeções periódicas
- Controle de qualidade

**Campos principais:**
- Dados do equipamento
- Itens verificados (OK/NOK)
- Peças substituídas
- Próxima manutenção

## 🔥 Fluxo Completo na Prática

### Cenário: Novo Cliente Solicita Orçamento

**ETAPA 1 - ORÇAMENTO (1 minuto)**
```
1. Templates > Orçamento
2. Preencher dados do cliente
3. Adicionar itens/serviços
4. Gerar PDF
5. Enviar ao cliente
```

**ETAPA 2 - CLIENTE APROVOU (30 segundos)**
```
1. Templates > Contrato
2. Dados já preenchidos
3. Adicionar cláusulas
4. Gerar PDF
5. Coletar assinaturas
```

**ETAPA 3 - EXECUTAR SERVIÇO (45 segundos)**
```
1. Templates > Check-list
2. Marcar itens verificados
3. Registrar observações
4. Gerar PDF
5. Arquivar
```

**ETAPA 4 - FINALIZAR (30 segundos)**
```
1. Templates > Relatório Técnico
2. Descrever serviços executados
3. Adicionar recomendações
4. Gerar PDF
```

**ETAPA 5 - ENTREGAR (15 segundos)**
```
1. Templates > Termo de Garantia
2. Definir cobertura
3. Gerar PDF
4. Entregar ao cliente
```

**TOTAL:** 3 minutos e 15 segundos para documentação completa!

## 🆘 Solução de Problemas

### Documento não gera PDF
```
✅ Verifique se preencheu todos os campos obrigatórios
✅ Configure os dados da empresa primeiro
✅ Limpe o cache do navegador
```

### Dados da empresa não aparecem
```
✅ Vá em Configurações
✅ Salve novamente as informações
✅ Gere o documento novamente
```

### PDF não baixa
```
✅ Verifique permissões de download
✅ Desative bloqueadores de popup
✅ Tente em modo anônimo
```
