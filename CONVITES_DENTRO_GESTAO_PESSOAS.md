# ✅ Convites Integrado em Gestão de Pessoas

## 🎯 FEITO! Convites agora é uma aba dentro de Gestão de Pessoas

A funcionalidade de **Convites de Usuários** foi movida para dentro da página **Gestão de Pessoas**, junto com as outras abas (Funcionários, Usuários, Perfis de Acesso).

---

## 📍 Como Acessar

### **Passo a Passo:**

1. No menu lateral, clique em:
   ```
   👥 Gestão de Pessoas
   ```

2. Dentro da página, você verá 4 abas no topo:
   ```
   [Funcionários] [Usuários do Sistema] [Perfis de Acesso] [Convites de Usuários]
   ```

3. Clique na aba **"Convites de Usuários"**

## 📊 Estrutura Completa

### **Gestão de Pessoas - 4 Abas:**

1. **👥 Funcionários** (Azul)
   - Cadastro de funcionários
   - Dados pessoais, endereço, banco, documentos
   - Upload de fotos
   - Convite rápido por card

2. **👤 Usuários do Sistema** (Verde)
   - Gerenciar contas de acesso
   - Ativar/desativar usuários
   - Definir permissões

3. **🛡️ Perfis de Acesso** (Roxo/Rosa)
   - Administrador, Gerente, Técnico, Externo
   - Permissões por perfil
   - Níveis de acesso

4. **➕ Convites de Usuários** (Laranja/Âmbar) ← **NOVO!**
   - Enviar convites por email/WhatsApp
   - Gerenciar convites pendentes
   - Ver histórico de convites
   - Reenviar convites expirados
   - Cancelar convites

## 🚀 Fluxos de Uso

### **Fluxo 1: Convite Completo (Nova Aba)**

```
1. Menu → 👥 Gestão de Pessoas
2. Clica na aba "Convites de Usuários"
3. Clica [+ Novo Convite]
4. Preenche email, WhatsApp, função
5. Escolhe método (email/WhatsApp/ambos)
6. Envia
7. Acompanha status na lista
```

**Use quando:**
- Precisa controle total
- Quer ver histórico
- Vai reenviar convite
- Convida pessoa externa

---

### **Fluxo 2: Convite Rápido (Card do Funcionário)**

```
1. Menu → 👥 Gestão de Pessoas
2. Já está na aba "Funcionários" (padrão)
3. Localiza card do funcionário
4. Clica [📧 Email] ou [💬 WhatsApp]
5. Confirma
6. Pronto!
```

**Use quando:**
- Funcionário já cadastrado
- Quer máxima rapidez
- Dados já estão corretos
- Onboarding em massa

## 🆘 Solução de Problemas

### **Não vejo a aba de Convites:**

1. **Limpe o cache:**
   - Ctrl+Shift+Del
   - Ou Ctrl+F5

2. **Verifique a URL:**
   - Deve ser `/people`
   - Não `/convites-usuarios`

3. **Recarregue:**
   - F5 ou Ctrl+R

4. **Teste outro navegador:**
   - Chrome, Firefox, Edge

---

### **A aba não responde:**

1. **Clique novamente**
2. **Verifique console:**
   - F12 → Console
   - Procure erros
3. **Recarregue a página**

---

### **Convites não aparecem:**

1. **Verifique conexão**
2. **Aguarde carregar**
3. **Verifique filtros**
4. **Recarregue aba**
